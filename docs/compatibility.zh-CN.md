# 兼容性与隐私

[English](compatibility.md) · [README](../README.zh-CN.md)

## 两层独立 Desktop 能力

| 界面 | 契约 |
| --- | --- |
| 底部建议芯片 | 任何支持公开 `host.composer.setDraft(sessionId, text)` 的 Desktop；始终可编辑，绝不发送。 |
| 草稿保护 | 若有公开 `getDraft(sessionId)`：空白或去除首尾空白后与建议相同的草稿一次填入；其他非空草稿须 5 秒内再次点击同一建议。 |
| 无 `getDraft` 的旧宿主 | 保留直接替换草稿能力；点击前请保存已有文字。 |
| 无 `setDraft` | 禁用芯片并提示升级，不使用私有 DOM/事件。 |
| 输入框原生灰字预览 | 需包含 PR #151206 的 Desktop，可选 `setPredictions` / `clearPredictions`，不由 CLI 版本推断。 |
| 生成 | 宿主现有网关 `session.history` 后执行一次 `llm.oneshot`，任务 `composer_predictions`、当前 session/profile，超时 150000ms。 |
| 持久化标识 | 内部 ID `conversation-guidance`；默认英文/可选 `zh-CN` 与开关通过 `ctx.storage` 保存。 |

Manifest/目录的 `>=0.23.0` 是保守的已发布 CLI/目录基线，不保证原生预览可用，也不代表最早 Desktop 版本。CLI 本身不承载此 UI。生成还要求网关 `llm.oneshot` 路由和模型正常配置。

## 原生发布所有权

仅当作用域字段均为非空字符串时发布 `{ sessionId, profile, connectionId, suggestions }`。请求过期或身份变化后丢弃结果，不给旧结果贴新作用域。保留宿主返回的不透明 `ComposerPredictionHandle` **原对象**，不复制或序列化，绝不向 `clearPredictions` 传 session 字符串。发布返回 `null` 时不丢失已有待清理句柄。重新生成、禁用、会话/profile/connection 切换或卸载/热重载时清理同一对象。SDK 契约保证旧句柄清理不会误删其他发布者的新预览。

宿主负责 **Tab** 循环切换 / **→** 接受到可编辑草稿 / **Esc** 隐藏；Shift+Tab 保留焦点导航。空草稿、可见/聚焦/空闲输入框、输入法和斜杠/提及菜单条件均由宿主判断；无适用预览时不拦截按键，接受绝不发送。缺少 `setPredictions`、作用域不完整或发布被拒不影响底部三条芯片及点击填入。重载插件无法增加宿主接口。真实键盘/输入法仍需真实窗口验证。

## 草稿替换保护

有 `getDraft` 时每次写入前先 await 检查。草稿含其他非空文本时首次点击不覆盖，并用中英双语 `info` 通知提示 5 秒内再次点击同一建议。换点其他建议会切换待确认目标并重新提示。过期、草稿编辑、会话/profile/connection 切换、禁用、重新生成或卸载均重置确认；重置后才返回的异步读取会被忽略。空白或去除首尾空白后与建议相同的草稿直接填入。读取失败只报通用错误，不写草稿。无 `getDraft` 时向后兼容，直接调用 `setDraft`。不自动发送、不读取私有 DOM。SDK 无原子 compare-and-set 草稿操作：这是点击保护，不是事务式编辑锁。

## 准入第 13 条披露 / 数据流

1. 助手回合结束（或打开符合条件的会话/手动刷新）后，通过现有网关读取当前会话历史。
2. 仅取最近六条非空可见 user/assistant 消息，文本合计最多 12,000 字符，优先保留较新文本；排除系统、工具和隐藏推理。
3. 每次生成执行一次辅助请求：`llm.oneshot`，`task: 'composer_predictions'`，当前 session/profile，超时 150000ms。上下文和指令经宿主发送给配置的提供商，适用其费用和数据保留政策；指令及格式不计入消息文本上限。
4. 过滤至最多三条建议，丢弃过期结果。切换界面语言不重发模型请求。
5. 仅点击或接受才写草稿，不写会话历史，不自动发送回合。`getDraft` 仅本地读取当前草稿确认替换，不将其作为额外模型上下文。

不读取凭据文件/凭据库，无直接第三方网络客户端、外部遥测、运行时 shell、后台进程、自更新或额外后端 tools/hooks/middleware/env。仅持久保存语言与开关；候选、句柄和确认仅存内存。本地安装器仅写入选定插件文件、收据和冲突备份，保留其他数据与偏好。**可见秘密不脱敏**。关闭阻止新请求，无法取消已发调用及费用；宿主诊断/提供商保留政策不由插件控制。

## 排查

- 没有建议：开启功能，打开以助手回复结束的会话，再点 `↻`。
- 失败：检查网关、提供商和任务路由后手动重试，勿在公开报告中附对话或凭据。
- 首次点击没替换：查看提示；支持 `getDraft` 时已有文字须 5 秒内再次点击同一建议。
- 芯片可用但无灰字：宿主无 PR #151206、作用域不完整，或输入框不符合预览条件。
- 安装拒绝：检查已有文件。安装的 `--force` 会备份不同内容，卸载永远不删除已编辑文件。
